## A. 安装与导航
- [ ] 首次安装：安装向导完成后直接进入会话页（UI 形态）。
- [ ] 导航只有：安装 → 会话 → 设置 › 模型 → 关于（设置页末尾「关于」）；找不到旧的抽屉、设置首页、文件浏览器、Git 页、用量页、会话树页、回收站页。
- [ ] 系统「分享到」列表里没有 pi-go。
- [ ] 设置 › 模型：服务商、OAuth 登录、自定义服务商、默认模型、网络代理、修复运行环境、关于都能打开。

## B. 两形态共用会话与引擎（硬性要求 ②）
- [ ] 终端形态执行 `!echo $PPID` 记下 PID₁ 与 `/session` 的 sessionFile₁；切到 UI 再切回终端，再执行一次：PID、sessionFile 都不变。
- [ ] 发送「从 1 数到 300，每行一个数」，生成期间每 1.5 秒切换一次、共 6 次：回复不中断、以 300 结束；没有出现「正在启动 / 已停止 / 崩溃」。
- [ ] 接着发「刚才最后一个数是几？」：回答包含 300（上下文保留）。
- [ ] 录屏：切换前后流式文字不闪烁、不跳到顶部；切换后列表仍贴底；切换动画约 120ms。
- [ ] 草稿：输入「草稿abc」、光标放在第 3 个字后、加 1 张图片、加一个 `@文件`，切换两次：文字、光标、图片缩略图、`@` 引用都还在。
- [ ] 扩展对话框（confirm）弹出时切换：对话框仍在，点「确定」后扩展收到结果（不是取消）。
- [ ] `/model` 面板打开、搜索框输入「son」时切换：面板和搜索词都还在。
- [ ] 关掉 App 再打开：停在上次的形态。

## C. 终端形态
- [ ] 页眉、消息区、状态行、编辑器、页脚、键条与 pi 一致（JetBrains Mono，无连字；双指缩放 10–18sp）。
- [ ] `/model` 选中一个已配置的模型：切换成功并**自动关闭面板**，页脚模型名更新；选未配置的模型进入服务商表单，保存 Key 后自动选回。
- [ ] `/login`、`/logout`、自定义服务商表单：保存失败时表单不关、已填内容不丢；OAuth 失败时可「重试」。
- [ ] 返回键：有面板时先关面板（登录中的 OAuth 被取消）；扩展对话框不被返回键关掉；什么都没有时 App 退到后台、生成不中断。
- [ ] 键条 ＋ / 外接键盘粘贴图片键：打开系统照片选择器，选中的图片出现在草稿里，切到 UI 也在。
- [ ] `@` 文件搜索出候选；`!` / `!!` 命令运行中按 Esc 能停。
- [ ] 外接键盘：Enter 发送、Shift+Enter 换行、↑↓ 翻历史不覆盖正在编辑的草稿、Ctrl+L 选模型、Ctrl+Alt+T 切形态。
- [ ] 长回复（1000 行以上）流式时滚动顺滑，无明显掉帧。

## D. UI 形态
- [ ] ⌘ 命令中心能找到 pi 的全部功能（对照 `docs/r3/coverage-map.tsv`），抽查：导出 HTML、分支树、压缩、会话信息、快捷键、复制最后回复。
- [ ] ＋ › 图片：系统照片选择器；发送带图片的消息，模型能看到图片。
- [ ] `/model` 选中模型后面板关闭、顶栏模型名更新。
- [ ] 返回键依次关：面板 → 展开的编辑器 → 会话列表 → 搜索；都关着时退到后台。

## E. 设置 › 模型 › 网络代理
