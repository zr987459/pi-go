## B. 需要人工在真机上看的项目

| 项目 | 操作 | 期望 |
|---|---|---|
| 抽屉返回键（Nit ①） | 打开抽屉 → 旋转屏幕 / 切换深色 → 按返回 | 先关抽屉，不退到后台；抽屉关着时返回才退到后台 |
| 外壳不随流式重组（Nit ②） | 生成长回复时打开抽屉、拖动会话列表 | 列表不卡顿、不闪 |
| 服务商表单回填（Nit ③） | Azure / Bedrock / Vertex 等多字段服务商：保存区域、项目后重进 | 非密文字段回填，Key 只显示末四位 |
| 设置入口（Nit ④） | 抽屉身份栏「设置」、聊天页「去设置模型」 | 前者进设置首页，后者进服务商页；旧设置页在「运行环境与高级」 |
| 会话内切模型 / 思考强度（Nit ⑤） | 生成中打开模型弹层切换 | 提示「从下一轮开始生效」，下一轮用新模型；思考强度同理 |
| OAuth 登录 | 服务商页选 Anthropic / GitHub Copilot 等 OAuth 服务商 | Custom Tab 打开授权页，回到 App 后显示已登录 |
| 代理与费用显示 | 设置首页「代理、费用显示」→ 填代理、打开人民币 | 重启 App 后仍生效；用量弹层显示「约 ¥」 |
| 会话树 | 抽屉「会话树」→ 折叠、从某节点分叉、复制会话 | 当前分支高亮；分叉后回到聊天且原文在输入框 |
| 技能与模板 | 抽屉「技能与模板」→ 停用一个技能 → 新建模板 | settings.json 出现 `-路径`；`/` 候选里出现新模板 |
| 用量页 | 抽屉「用量」 | 与聊天页弹层数字一致 |
| 消息复制 | 长按助手消息「复制」「复制 Markdown」 | 前者去掉 Markdown 记号，后者原文 |
| 按会话草稿 | 写一半草稿 → 切会话 → 切回；杀进程重开 | 草稿各归各的会话并能恢复 |
| 自动命名 | 新会话发两轮 | 会话标题自动更新（需要 Key 环境，W4 修复 2） |
| 文件页 | 抽屉「文件」→ 浏览、预览、Git 改动与 diff；「在此新建会话」；「@ 引用」 | 从当前会话 cwd 开始；返回键逐级返回；新会话 cwd 正确；输入框出现 `@路径` |
| 附件 | 输入框「+」→ 拍照 / 相册 / 文件 → 关闭弹层 | 图片进待发胶囊，文件以引用追加到草稿；纯文本模型拒绝图片 |
| 系统分享 | 在别的应用分享图片/文字/文件给 pi-go | 打开 App 并带上附件（FilesRuntime 冷启动已登记） |
| 轮末汇总点文件 | 点轮末汇总里改过的文件 | 直接打开文件预览 |
| 深色 / 浅色 | 各新页面切换主题 | 背景、玻璃面板、文字对比度正常 |
